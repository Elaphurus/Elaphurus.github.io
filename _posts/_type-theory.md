# 类型论

## 起源

### 古典数学的基础语言

类型论起源于对数学基础的研究。朴素集合论中存在着逻辑悖论，如罗素悖论：令 R 为所有那些不是自身元素的集合所组成的集合（$R=\{x|x \notin x\}$）。为解决这一问题，Zermelo 发展了公理化集合论（ZFC），Russell 开发了类型论。

然而，Russell 的分支类型论混淆并试图同时避免逻辑悖论与语义悖论（如说谎者悖论：这句话是假的），导致需要依赖有争议的归约公理（axiom of reducibility）。为此，Ramsey 建议将分支类型论简化为简单类型论。

简单类型论是高阶逻辑的一种表达方式，Church 以 $\lambda$ 演算为基础将其形式化。

### 构造性数学的逻辑基础

古典数学是经典逻辑，接受排中律（P 或非 P 必有一真）。只要能从假设出发，通过反证法证明“不存在反例”，就承认对象存在，即使无法具体构造出它。

构造性数学是构造主义逻辑，拒绝排中律。要证明“存在 x 使 P(x)”，必须明确给出构造 x 的具体方法（算法或有限步骤），并证明它确实满足 P。

在构造性数学的逻辑基础的研究中，Martin-Löf 将逻辑嵌入类型论，开启了现代类型论的研究和发展。

### 直谓

Martin-Löf 类型论是直谓的（predicative），即用一个已经存在的集合来定义它的子集或子对象，定义过程中不引用正在定义的这个对象本身，也不引用包含它的更大的集合。

简单类型论是非直谓的（impredicative）：在定义一个对象时，引用了一个包含该对象在内的更大的集合，或者引用了该对象本身。

### 现代类型论

构造演算 = 简单类型论 + 证明对象（命题及类型）

统一类型论（Unifying Theory of dependent Types，UTT） = Martin-Löf 类型论 + 构造演算

统一类型论的类型结构由两部分组成：
1. 各种数据类型，如自然数类型 $Nat$、依赖类型（如 $\Pi$ 类型、$\Sigma$ 类型等）等，及其所属的直谓类型空间；
2. 逻辑命题，如全称量词 $\forall$ 等，及其所属的非直谓空间。

## 证明助手

证明助手是基于现代类型论的计算机辅助推理系统。典型系统及其基于的现代类型论如下：

| 证明助手       | 基于的现代类型论    |
| ------------- | ---------------- |
| Agda          | Martin-Löf 类型论 |
| Coq           | 归纳构造演算       |
| Lego、Plastic | 统一类型论         |
